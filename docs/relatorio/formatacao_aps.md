# Diretrizes de formatação (manual APS UNIP)

Adotadas neste projeto após validação com a discente:

| Item | Valor |
|------|-------|
| Fonte | Arial 12 |
| Espaçamento | 1,5 |
| Papel | A4 |
| Margem esquerda | **2,5 cm** |
| Margem direita | **2,5 cm** |
| Margem superior / inferior | seguir padrão acadêmico coerente com o manual (sugestão: 2,5 cm, salvo orientação contrária do professor) |
| Normas | trabalho acadêmico ABNT, observadas as especificidades do manual da disciplina |

**Observação:** a NBR 14724 clássica usa 3,0 cm (esq./sup.) e 2,0 cm (dir./inf.). Neste APS, **prevalece o manual da disciplina (2,5 cm nas laterais)**.
